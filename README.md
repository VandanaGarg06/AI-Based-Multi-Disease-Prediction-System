
# AI-Based Multi-Disease Prediction System

## Project Overview
An AI-based system for predicting three diseases:
- Diabetes
- Heart Disease
- Chronic Kidney Disease (CKD)

- GOOGLE COLAB
- Trained Machine Learning Models
- Results and Graphs
- Streamlit Application
- Project Documentation
